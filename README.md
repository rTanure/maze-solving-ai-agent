# Trabalho prático - Agente solucionador de labirintos
## Como rodar

1. Crie o ambiente virtual: `python -m venv venv`
2. Ative o ambiente virtual
    - windows: `.\venv\Scripts\activate`
    - linux: `source venv/bin/activate`
3. Instale as dependências: `pip install -r requirements.txt`
3. Rode a aplicação: `python src/main.py`

## Instalando novas dependências

Rode o comando para instalas as dependências e, em seguida, atualize o arquivo requirements.txt.

```
pip install [dependency]
pip freeze > requirements.txt
```
